# ionos-mini firmware

Source snapshot of the two processors' firmware, taken from
[ionos-sdr](https://github.com/ionos-sdr/ionos-sdr), branch
`exp/fg23-ais-onchip` (commit `408f3a9`). Development continues there; this
copy is what runs on the measured units (ID1, ID2) as of 2026-11-23.

| folder | chip | build |
|---|---|---|
| [`esp32/`](esp32/) | ESP32-S3 (host: SPI slave, demods, TFT, WiFi, console) | PlatformIO, `pio run -e ionos_mini` |
| [`fg23/`](fg23/) | EFR32FG23 (radio: I/Q stream, scan, TX, on-chip AIS) | Simplicity Studio 5 / Simplicity SDK, GNU ARM 12.2 |

Not in the repo (git-ignored, make your own): `esp32/src/secrets.h` (WiFi,
APRS-IS), `fg23/station_config.h` (from `station_config.example.h`),
`esp32/src/fw_version.h` (generated by `tools/pio_fw_version.py`).

## AIS: two receive modes, one firmware

| mode | how | console |
|---|---|---|
| **IQ** (default) | FG23 streams I/Q (50 ksps around 161.985 MHz) over SPI, the ESP32 demodulates channel A (`esp32/src/ais_rx.*`) | `AISGO` |
| **native** | FG23 AIS PHY (2GFSK 9600 bd, LEGACY demod) + HDLC/CRC on the FG23 (`fg23/ais_hw.c`), finished frames to the ESP32 in AIS1 blocks; channel A or B | `AISHW1` (A), `AISHW2` (B), `AISHW0` back |
| **A/B bench** | alternates the two, msgs/min and per-station counts | `AISBENCH <min>`, `AISBENCH`, `AISBENCH 0` |

Both modes emit the same console lines (`AIS RX:` / `AIS RX[HW]:`), NMEA on
TCP 10110 and `$PIONS,...,<IQ|HW>,<dBm>`. Description and commands:
[`docs/fg23-ais-onchip.md`](../docs/fg23-ais-onchip.md); measurements:
[`measurements/ionos-mini-2026-11-23-ais-onchip/`](../measurements/ionos-mini-2026-11-23-ais-onchip/RESULT.md).

Unit identity (serial, fw version, build / manufacturing / programming date on
the TFT): console `SERIAL <id>`, `MFG <date>`, `ID`.

## FG23 radio configuration

`fg23/config/rail/radio_settings.radioconf` holds all PHYs; the AIS entry is
channels 3000–3001. `fg23/tools/rc_gen.py` regenerates `autogen/rail_config.c/.h`
without the Studio GUI (the SDK's own Multi-PHY configurator, Studio's Python).
The AIS entry needs the `demod_select = LEGACY` override — the configurator's
default TRECS demod does not sync on AIS.

## Flashing

- ESP32: `pio run -e ionos_mini -t upload`, or esptool `write-flash 0x10000
  firmware.bin` (16 MB, `partitions_16mb_fs.csv`).
- FG23: through the ESP32 (SWD bit-bang), `python esp32/tools/fg23_flash.py
  <hex> --port <COM>`, then `FGRST` on the console (the FG23 stays halted after
  flashing).
